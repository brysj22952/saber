赛博手写笔记 隐私政策

适用于「赛博手写笔记」的 HarmonyOS(鸿蒙)版本 · 最后更新:2026 年 11 月

一句话总结:你的笔记默认只保存在你自己的设备上。 本应用没有广告、没有统计 SDK、不收集任何个人信息,也不采集崩溃日志。

1. 这个应用是什么

赛博手写笔记 是一个开源的手写笔记应用, 基于开源项目 Saber(由 Adil Hanney 开发并开源)开发。 本应用是它的 HarmonyOS(鸿蒙)版本,使用 HarmonyOS 原生工具链 (Flutter-OH / ArkTS)编译,面向 HarmonyOS NEXT 设备运行。

2. 我们会收集哪些数据

我们不收集任何个人信息。具体来说,本应用不会收集、上传或分享:

  • 姓名、邮箱、手机号、通讯录、位置信息;
  • 设备标识(IMEI、MAC、OAID、Android ID 等);
  • 你的笔记内容、图片、白板 —— 除非你自己主动开启同步并指定了自己的服务器;
  • 崩溃日志、性能数据、使用行为统计 —— 本应用没有接入崩溃上报与埋点 SDK, 设置页里也不存在任何此类开关(已在真机核对确认)。

应用运行时不会与我们的任何服务器通信,开发者也无法看到你的任何数据。

在你主动开启 Nextcloud 同步之前,本应用不会发出任何网络请求 —— 包括不会在启动时自动联网检查版本更新(版本检查默认关闭,只有在你自己触发时才会发生); 整个笔记应用完全在你的设备上本地运行。

3. 数据存在哪里

你的笔记、图片、白板和应用设置,默认只写在本机的应用私有目录里 (HarmonyOS 沙箱机制保护,其他应用无法读取)。

应用只申请了一个系统权限:

权限用途什么时候用到
ohos.permission.INTERNET访问网络 仅当你主动开启 Nextcloud 同步并填写服务器地址后才会用到; 平时完全离线可用。

应用不申请定位、相机、麦克风、通讯录、剪贴板等权限。 「导入笔记」「从图库选图片」使用的是 HarmonyOS 系统自带的文件选择器, 由系统临时授权、一次一用,应用不会因此获得相册或文件系统的长期访问权。

4. 开启 Nextcloud 同步之后

同步功能是完全可选的,你可以永远不开启。开启后:

  • 服务器地址、用户名、密码由你自己填写,保存在本应用的私有目录 (HarmonyOS 应用沙箱)里,不会上传、也不会同步到任何服务器;沙箱隔离保证其它应用读不到它们。
  • 技术说明(如实告知):本 HarmonyOS 版本目前是把上述凭据以及本机的 笔记加密密钥放在应用私有目录中保存,尚未 接入鸿蒙的硬件密钥托管服务(HUKS),因此它们在本机不是 硬件加密存放的;后续版本会改用 HUKS 加密保存。 上面的「应用沙箱隔离」是当前实际生效的保护措施。 (笔记密钥在服务器上的副本由你设置的「笔记加密口令」加密保护 ✓)
  • 笔记在上传前会用随机密钥加密,服务端保存的是密文;
  • 数据只在你自己的 Nextcloud 服务器与你的设备之间传输 —— 我们没有、也拿不到你的服务器地址和账号密码;
  • 你可以在「设置」里随时注销,一键删除已保存的凭据并停止同步。

5. 数据保留与删除

  • 本地数据随应用一起存在,直到你手动删除笔记或卸载应用;
  • 卸载应用即删除全部本地数据(包括笔记、图片、白板、设置和已保存的凭据);
  • 已经同步到你自己服务器上的数据,由你在服务器端自行管理 —— 卸载应用不会自动删除服务器上的副本。

6. 权限与网络的可控性

同步可以随时关闭。关闭后本应用不再发起任何网络请求。 HarmonyOS 系统层面,你也可以随时在「设置 → 应用 → 权限」中撤销本应用的网络权限。

7. 政策变更

本政策如有变更,会随代码仓库一起更新(见第 1 节的仓库地址), 历史版本可在 GitHub 的提交记录中查看。

8. 联系我们

对本政策或应用本身有疑问,请在仓库里提 issue: https://github.com/brysj22952/saber/issues。

English summary

赛博手写笔记 is an open-source handwritten notes app, built on the open-source Saber project by Adil Hanney. This is the HarmonyOS (HarmonyOS NEXT) build, compiled with the HarmonyOS native toolchain. The upstream project lives at github.com/saber-notes/saber; this HarmonyOS port, including its full build chain, is at github.com/brysj22952/saber (branch feature/ohos-harmonyos). Both are licensed under GPL-3.0.

Your notes, images and whiteboard are stored only on your device by default. We collect no personal information, ship no ads and no analytics SDK, and do not collect crash logs. The app requests a single permission, ohos.permission.INTERNET, which is used only if you opt in to Nextcloud sync. Until you do, the app makes no network requests at all — it does not even check for updates in the background; the whole app runs locally on your device. With sync enabled, the server URL and credentials are kept in the app's private directory (protected by HarmonyOS app sandboxing, and never uploaded or synced to any server we can reach), and your notes are encrypted with a random key before upload. For the record: this HarmonyOS build stores those credentials in the app's private directory and does not yet use the HarmonyOS hardware key service (HUKS), so neither they nor the local copy of your note-encryption key are hardware-encrypted at rest; a later release will move both to HUKS. (The copy of the note-encryption key stored on your own server is protected by the encryption password you set.) the data travels only between your device and the Nextcloud server you chose. Uninstalling the app deletes all local data.
