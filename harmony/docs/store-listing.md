## 2. 应用介绍(长文本)

```
赛博手写笔记 是一款专注手写的开源笔记应用,支持手写笔与手指书写,提供压感笔迹、多色画笔、形状识别、撤销重做等完整绘图能力;白板模式可以随手演算草稿。所有笔记、图片和白板默认只保存在你自己的设备上,完全离线可用;需要多设备同步时,可以自行连接你自己的 Nextcloud 服务器,笔记在上传前会用随机密钥加密。

本应用是开源项目,并针对 HarmonyOS(鸿蒙)设备编译、适配 HarmonyOS NEXT。源代码完全公开:

· 官方开源项目(Saber 本体):https://github.com/saber-notes/saber
· 本鸿蒙版本(含完整鸿蒙构建链):https://github.com/brysj22952/saber

本应用无广告、无统计 SDK、不采集崩溃日志、不收集任何个人信息,仅申请网络权限,且仅在用户主动开启同步时使用。
```

## 3. 权限说明

```
仅申请 ohos.permission.INTERNET(访问网络)。该权限仅在用户主动开启 Nextcloud 同步、
并连接自己指定的服务器时才会使用;不开启同步时应用完全离线运行。

不申请定位、相机、麦克风、通讯录、相册、剪贴板等任何其他权限。
「导入笔记」「从图库选择图片」使用 HarmonyOS 系统自带的文件选择器,由系统临时授权、
一次一用,应用不会因此获得相册或文件系统的长期访问权限。

应用不含广告 SDK、不含统计/埋点 SDK、不采集崩溃日志、不收集任何个人信息。
本移植版本未集成任何第三方崩溃上报 SDK,应用不会向用户征求错误上报的同意,
也不会把崩溃数据或使用数据发送到任何第三方服务器。
```

> 图标与截图都要从**商店素材**维度准备:图标 1024×1024;截图按设备类型分开上传,
> 平板用 `harmony/docs/store-screenshots/` 里的四张(只截应用窗口,不含桌面与个人信息)。

> **包内图标为什么是 512 而不是 1024**:SDK 的 restool 会把包内图标归一化到
> 512×512,而且 1024→512 的缩放会经图像转码器转成 **RGBA alpha=254**
> ——等于又踩「图标有透明背景」那条阻塞项。所以包内直接放 **512×512 RGB**
> (就是商店那张 1024 的 LANCZOS 缩放,逐像素可验证一致),restool 会原样拷贝,
> 不转码、不带 alpha。详见 [DEPLOY-RECORD.md](DEPLOY-RECORD.md) §2026-11-18。
